COMO LER A SÉRIE
De v1 a v7 a página não cresce só em conteúdo: ela vai tirando suposições. v1 exige nove casas por regra; v2 troca isso por uma seta; v4 para de supor que a fita existe; v7 para de supor que duas línguas cabem no mesmo espaço. O raciocínio de cada passo está em Cellula Rules Timeline.
FIDELIDADE
v5, v6 e v7 são fiéis: as diferenças eram de texto e de idioma, e eu as desfiz exatamente. v1 a v4 são honestas no que havia e no que faltava, mas o detalhe visual dos blocos removidos é reconstruído — não confie neles para medir pixels.
